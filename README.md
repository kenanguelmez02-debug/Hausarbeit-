# Hausarbeit

## Humanizer-Skill

Unter `.claude/skills/humanizer/` liegt der Skill [Humanizer](https://github.com/blader/humanizer) (v3.1.0, MIT-Lizenz, Stand Commit `0ef9fe5`).
Er überarbeitet Text, der nach KI klingt, ohne den Inhalt zu ändern.

In Claude Code in diesem Repository verwenden:

```
/humanizer <Text einfügen>
```

oder für eine Datei:

```
Humanize the prose in kapitel1.md
```

Aktualisieren: `SKILL.md` aus dem Upstream-Repository neu kopieren.
